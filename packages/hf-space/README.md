# Calculadora IMC (BMI calculator)

A free, bilingual (Spanish/English) adult BMI calculator that runs in the browser:

- kg/cm or lb/in, comma or dot decimals, height in cm or metres
- WHO class with thinness subclasses and obesity classes I–III, highlighted in the table
- BMI rounded to 1 decimal before it is classified (24.96 → 25.0 → overweight)
- healthy-weight range for your height and how many kg you are above or below it
- nothing is sent anywhere; all maths runs in the page

BMI is a general screening measure for adults and is not medical advice.
